# CatCasino

![CatCasino Preview](https://github.com/user-attachments/assets/7562cdd8-4b67-4459-b4f0-cf842198ec99)

A modular console-based gambling simulator developed in C++. The project focuses on resource management, probability, and progressive game balance.

## Core Features

*   **Modular Architecture**: The source code is divided into discrete functional modules (taxation, shop, game logic, rendering), facilitating maintainability and scalability.
*   **Input Validation**: Integrated robust error handling for user inputs to prevent runtime crashes and ensure data integrity.
*   **Progressive Game Balance**:
    *   **Dynamic Taxation**: Tax rates scale non-linearly based on the player's current capital to prevent rapid inflation.
    *   **Adaptive Multipliers**: Win coefficients adjust dynamically based on the player's total balance to maintain difficulty.
*   **Advanced Randomization**: Implements `std::mt19937` (Mersenne Twister) for high-quality pseudo-random number generation.

## Project Structure

| File | Description |
| :--- | :--- |
| `main.cpp` | Entry point and primary game loop execution. |
| `tax.cpp` | Logic for calculating progressive tax deductions. |
| `shop.cpp` | Management of the in-game item system and transactions. |
| `headings.h` | Global structure definitions and function prototypes. |
| `draw.cpp` / `logo.cpp` | Console rendering functions and ASCII art implementation. |
| `GetValidInput.cpp` | Utility functions for safe data stream processing. |

## Technical Requirements

*   C++11 compliant compiler or higher.
*   Windows OS (utilizes `windows.h` for timing and console management).

## Build and Run

1. Clone the repository.
2. Open the `.sln` solution file in Visual Studio or compile via G++.
3. Execute the generated binary.
